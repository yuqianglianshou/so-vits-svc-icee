# 环境与兼容性

本文记录当前发布路线的支持边界。没有完成实际验证的组合不会标记为“已支持”。

## 当前主线

| 项目 | 当前结论 |
| --- | --- |
| 操作系统 | Windows 10/11 64 位为主要发布平台 |
| GPU | NVIDIA GPU |
| Python | 3.11 |
| 应用入口 | `python -m src.app_train`、`python -m src.app_infer` |
| 训练方式 | 单说话人、单模型工作区 |
| 采样率 | 44.1 kHz 主路线 |
| 内容编码器 | ContentVec `vec768l12` |
| F0 | RMVPE |

## PyTorch 与 CUDA

项目不在文档中长期维护一条固定的 PyTorch 下载命令，因为驱动、CUDA 和 PyTorch 可用组合会变化。安装时请使用 [PyTorch 官方安装页面](https://pytorch.org/get-started/locally/)生成命令。

安装后执行：

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.version.cuda)"
```

正式训练前，`torch.cuda.is_available()` 必须输出 `True`。

## 其他平台

### Linux

代码中的训练和推理逻辑理论上可运行，但当前发布流程没有完成与 Windows 相同的端到端验收，因此暂不标记为正式支持。

### macOS

可用于文档、页面和轻量静态检查，不建议作为正式训练平台。训练入口要求 CUDA。

## 显存与训练耗时

模型显存占用和训练耗时受 GPU、batch size、数据量、音频长度、是否启用扩散以及磁盘速度影响。当前版本不承诺统一的最低显存和训练时长。

显存不足时应先降低 batch size，不要通过删除错误处理或随意修改模型结构绕过问题。

## 发布验收状态

每次正式发布前，维护者应在 [开发与发布检查](90_开发与发布检查.md) 中记录实际验证的 Windows、GPU、驱动、Python、PyTorch 和 CUDA 版本。未填写人工验收记录时，版本只能视为 Release Candidate。
