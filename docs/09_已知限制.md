# 已知限制

本文用于说明当前发布边界，不代表所有列出的能力永远不会支持。

## 平台

- Windows 10/11 + NVIDIA GPU 是当前主要验证路线。
- Linux 尚未完成同等级的端到端发布验证。
- macOS 不建议用于正式训练。
- CPU 训练不受支持。

## 训练

- 当前主线面向单说话人模型。
- 数据质量会显著影响结果，项目不能自动修复严重伴奏残留、混响、削波或错误授权。
- 训练耗时和显存占用没有统一保证。
- 页面显示训练任务已启动，不等于最终模型一定收敛或达到特定音质。
- 浅扩散和特征检索是可选增强路线，不保证对所有数据都改善听感。

## 推理

- 当前重点是离线转换，不是实时变声。
- 极端跨音域、严重跑调、强混响或带伴奏输入可能产生明显伪影。
- 模型相似度、咬字和自然度之间可能存在取舍。
- ONNX 相关工具保留用于兼容和实验，不属于本次发布的主要支持流程。

## 兼容性

- 项目尽量保持 so-vits-svc 4.1 模型兼容路线，但无法保证所有第三方修改版模型可直接加载。
- 导入模型时必须同时保留与模型匹配的 `config.json`。
- 旧扩散模型与不同声码器的 mel 定义可能不兼容。

## 模型与数据

- 仓库不提供训练完成的角色或真人模型。
- 用户必须自行取得训练数据、输入音频和发布内容的授权。
- 自动下载依赖依赖第三方托管服务，链接可能失效或在部分网络环境不可用。

## 尚未执行的发布验证

如 [开发与发布检查](90_开发与发布检查.md) 中的 Windows 人工验收表仍标记为“未执行”，当前版本应视为 Release Candidate，而不是完成全部环境验证的正式稳定版。
