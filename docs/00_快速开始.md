# 快速开始

本文只描述第一次成功运行的最短路径。出现异常时不要跳过错误，请进入 [Windows 常见问题排查](02_Windows常见问题排查.md)。

## 1. 准备环境

建议使用 Windows 10/11、NVIDIA GPU 和 Python 3.11。安装 Git、FFmpeg、Python 3.11 和适合显卡的 NVIDIA 驱动。

克隆仓库并进入项目目录：

```powershell
git clone https://github.com/yuqianglianshou/so-vits-svc-icee.git
cd so-vits-svc-icee
```

创建并激活虚拟环境：

```powershell
python -m venv .venv311
.venv311\Scripts\activate
python -m pip install --upgrade pip
```

按照 [PyTorch 官方安装页面](https://pytorch.org/get-started/locally/)选择适合当前 CUDA 环境的命令，安装 PyTorch 和 torchaudio，然后运行：

```powershell
pip install -r requirements.txt
```

## 2. 启动训练页

双击 `launchers/启动训练界面.bat`，或在已激活的虚拟环境中运行：

```powershell
python -m src.app_train
```

浏览器没有自动打开时，使用终端显示的本地网址。

## 3. 补齐依赖

打开训练页的“训练前依赖与底模”：

1. 逐项查看缺失状态。
2. 优先使用“自动获取当前依赖”。
3. 自动获取失败时，使用页面提供的链接手动下载并导入。
4. 确认所有准备使用的功能所需资产显示为已存在。

文件作用和目标路径见[模型依赖清单](08_模型依赖清单.md)。

## 4. 创建工作区并导入音频

1. 新建训练模型并输入简短、稳定的模型名。
2. 导入已经获得合法授权的 WAV 音频。
3. 优先使用干净、无伴奏残留、无明显混响和削波的单人音频。
4. 确认页面能够显示导入的 WAV 数量。

## 5. 执行训练流程

按页面顺序执行：

1. 重采样。
2. 生成配置与文件列表。
3. 提取 ContentVec、F0 和训练特征。
4. 启动主模型训练。
5. 按需训练浅扩散模型。
6. 按需训练音色增强索引。

首次验证可以先完成第 1～4 步。扩散和索引不是确认主训练流程能运行的前提。

## 6. 完成一次推理

双击 `launchers/启动推理界面.bat`，或运行：

```powershell
python -m src.app_infer
```

选择工作区模型和 checkpoint，导入输入音频，先使用默认质量模式完成一次转换。输出保存在 `inference_data/outputs/`。
