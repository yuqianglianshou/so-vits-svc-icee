# 项目现状与维护建议

这份文档给维护者看，说明当前仓库的主入口、结构、已完成改动和下一步优先级。新手使用请从 [文档索引](README.md) 开始。

## 1. 当前定位

当前项目主线是本地 GUI 工作流：

1. 训练页：`python -m src.app_train`
2. 推理页：`python -m src.app_infer`

项目目标是让用户能在 Windows + NVIDIA GPU 上完成：

1. 补齐训练前依赖与底模。
2. 导入单说话人数据。
3. 按 1-6 步训练。
4. 打开推理页做离线高质量转换。

## 2. 当前目录结构

```text
src/
├── app_train.py          # 训练页入口
├── app_infer.py          # 推理页入口
├── train_ui/             # 训练页 UI、状态、任务和启动辅助
├── infer_ui/             # 推理页模型、转换、导出和文本辅助
├── train_pipeline/       # 重采样、配置生成、特征提取、训练
├── inference/            # 推理主逻辑
├── diffusion/            # 扩散模型
├── vencoder/             # ContentVec 等内容编码器
└── vdecoder/             # 声码器
```

核心数据目录：

```text
training_data/source/             # 原始训练音频
training_data/processed/          # 处理后训练数据
inference_data/inputs/            # 推理输入
inference_data/outputs/           # 推理输出
model_assets/dependencies/        # 训练前依赖与底模
model_assets/workspaces/          # 训练产物
model_assets/imported_models/     # 已导入推理模型
```

## 3. 当前已完成的关键收敛

1. 入口收敛到 `src.app_train` 和 `src.app_infer`。
2. 依赖收敛到单一 `requirements.txt`。
3. 训练页负责依赖检查、自动获取、文件导入、数据导入、训练任务和日志。
4. ContentVec HF 依赖已细化到 `config.json` / `model.safetensors` 文件级状态。
5. TensorBoard 和推理页慢启动时会显示提示，并在服务就绪后尝试打开浏览器。
6. 推理页支持训练工作区、已导入模型、质量模式和运行摘要。

## 4. 当前推荐维护原则

1. 优先保证 Windows + NVIDIA GPU 闭环稳定。
2. 新功能先接进训练页或推理页，不再新增分散入口。
3. 依赖文件继续保持单一 `requirements.txt`。
4. 文档优先围绕本地 GUI 工作流维护。
5. 不要把实验路线直接替换成默认主线。
6. 每次改训练页/推理页流程后，至少运行：

```bash
python3 scripts/verify_app_smoke.py
```

## 5. 下一步优先级

高优先级：

1. Windows + GPU 真机完整验证训练 1-6 步。
2. 验证推理页加载训练工作区模型的稳定性。
3. 补最小 UI / 纯函数 smoke test。
4. 继续增强中文错误提示。

中优先级：

1. 清理训练脚本里的临时 `print(...)`。
2. 统一日志格式。
3. 对音频文件大小、格式、目录结构做更明确校验。
4. README 与 docs 索引继续对齐。


## 6. 回归检查清单

改动后建议至少确认：

1. `python3 -m py_compile src/app_train.py src/app_infer.py`
2. `python3 scripts/verify_app_smoke.py`
3. 训练页能打开。
4. 推理页能打开。
