# 模型依赖清单

训练页会显示各项资产的实时状态，并提供自动获取或手动导入入口。建议优先使用页面操作，避免下载到错误目录。

## 资产一览

| 资产 | 用途 | 项目内目标位置 | 使用范围 |
| --- | --- | --- | --- |
| ContentVec `config.json` | 定义内容编码器结构 | `model_assets/dependencies/encoders/contentvec_hf/config.json` | 主训练与推理必需 |
| ContentVec `model.safetensors` | 内容编码器权重 | `model_assets/dependencies/encoders/contentvec_hf/model.safetensors` | 主训练与推理必需 |
| `rmvpe.pt` | 提取人声音高 F0 | `model_assets/dependencies/encoders/rmvpe.pt` | 当前训练主线必需 |
| `G_0.pth` | 主模型生成器底模 | `model_assets/dependencies/base_models/44k/G_0.pth` | 推荐用于主模型训练 |
| `D_0.pth` | 主模型判别器底模 | `model_assets/dependencies/base_models/44k/D_0.pth` | 推荐用于主模型训练 |
| `model_0.pt` | 浅扩散底模 | `model_assets/dependencies/base_models/44k/diffusion/model_0.pt` | 仅扩散训练需要 |
| NSF-HiFiGAN `model` | 歌声声码器权重 | `model_assets/dependencies/vocoders/nsf_hifigan/model` | 扩散和增强功能需要 |
| NSF-HiFiGAN `config.json` | 声码器配置 | `model_assets/dependencies/vocoders/nsf_hifigan/config.json` | 扩散和增强功能需要 |

## 推荐准备方式

1. 启动训练页。
2. 打开“训练前依赖与底模”。
3. 选择显示缺失的资产。
4. 优先点击自动获取。
5. 自动获取失败时使用页面显示的来源链接。
6. 下载完成后通过页面导入，不要随意改名。

## 当前代码使用的公开来源

- RMVPE：[官方发布包](https://github.com/yxlllc/RMVPE/releases/download/230917/rmvpe.zip)
- 主模型和扩散底模：[Sucial/so-vits-svc4.1-pretrain_model](https://huggingface.co/Sucial/so-vits-svc4.1-pretrain_model)
- NSF-HiFiGAN：[OpenVPI vocoders 发布页](https://github.com/openvpi/vocoders/releases/tag/nsf-hifigan-v1)

ContentVec 文件的实际来源链接以训练页当前显示为准。第三方托管内容可能变化，下载前应核对来源、文件名和授权条款。

## 常见错误

- `config.json` 被浏览器保存成网页：使用“另存为”，确认内容是 JSON。
- `model.safetensors` 下载中断：删除不完整文件后重新下载。
- `rmvpe.pt` 体积异常小：视为损坏，不要继续训练。
- NSF-HiFiGAN 解压后多一层同名目录：使用训练页导入，让项目完成目录归一化。
- 把训练产物放进依赖目录：训练产物应留在对应模型工作区。
