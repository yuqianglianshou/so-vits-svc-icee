# 音质配置推荐

这份文档只保留当前项目最需要维护的音质建议。安装和 Windows 操作流程请看 [Windows 安装、训练与推理指南](01_Windows安装训练推理指南.md)。

## 1. 当前稳定基线

推荐环境：

- Python：`3.11.x`
- Gradio：`4.44.1`
- PyTorch：Windows / Linux NVIDIA 环境优先使用 CUDA 版
- 依赖来源：仓库根目录的 `requirements.txt`

## 2. 当前推荐组合

| 模块 | 当前推荐 | 说明 |
| --- | --- | --- |
| 内容编码器 | `vec768l12` / HF ContentVec | 当前主线，读取 `contentvec_hf/` |
| ContentVec 文件 | `config.json` + `model.safetensors` | 两个都必须存在 |
| F0 预测器 | `rmvpe` | 当前默认推荐 |
| 主模型底模 | `G_0.pth` + `D_0.pth` | 主模型训练起点 |
| 扩散底模 | `model_0.pt` | 扩散训练起点 |
| 声码器 | `nsf_hifigan` | 当前扩散/增强链路仍使用 |
| 推理质量模式 | 默认或极致质量 | 先用默认，验收时再开极致 |

ContentVec 目录：

```text
model_assets/dependencies/encoders/contentvec_hf/
```

必须包含：

```text
config.json
model.safetensors
```

## 3. 训练侧建议

新手优先使用训练页，不建议直接跑底层训练命令。

训练页步骤：

1. 重采样。
2. 生成配置与文件列表。
3. 提取特征。
4. 主模型训练。
5. 扩散训练。
6. 训练音色增强索引。

建议顺序：

1. 先用少量干净数据跑通 1-4 步。
2. 确认能产出 `G_*.pth` 并推理成功。
3. 再补扩散训练和音色增强索引。
4. 最后扩大数据量做正式训练。

## 4. 推理侧建议

第一次验收时建议做三组对比：

1. 只加载主模型。
2. 主模型 + 扩散。
3. 主模型 + 扩散 + 音色增强索引。

听感重点：

1. 音准是否稳定。
2. 咬字是否清楚。
3. 音色是否像目标。
4. 尾音是否断裂或发虚。
5. 是否出现明显电音感或底噪。

## 5. 常用参数怎么调

### 5.1 变调

用于匹配输入音频和目标音区。

- 男声转女声通常需要升调。
- 女声转男声通常需要降调。
- 不确定时先从 `0` 开始，逐步试。

### 5.2 特征检索混合比例

作用：让输出更贴近目标音色，但比例过高可能影响咬字和自然度。

建议：

- 起点：`0.3` 到 `0.5`
- 音色不像：适当提高
- 咬字变糊：适当降低

### 5.3 浅扩散步数

作用：改善细节和质感，但会增加推理时间。

建议：

- 快速试听：较低步数
- 正式导出：较高步数
- 如果扩散后更糊或更怪，先关闭扩散对比主模型效果

### 5.4 batch size

作用：影响训练速度和显存占用。

建议：

- 显存不足：降低 batch size
- GPU 吃不满且显存充足：适当提高 batch size
- 不要一开始就把 batch size 拉太大

## 6. DataLoader 调优

当前训练配置支持：

```json
"num_workers": 5,
"pin_memory": true,
"persistent_workers": true,
"prefetch_factor": 2
```

Windows 推荐起点：

```json
"num_workers": 4,
"pin_memory": true,
"persistent_workers": true,
"prefetch_factor": 2
```

如果 `all_in_mem=true`，建议：

```json
"num_workers": 0,
"persistent_workers": false
```

原则：

1. 先确认训练能稳定跑。
2. 再看 GPU 利用率和磁盘占用。
3. 最后再调 `num_workers` 等吞吐参数。

## 7. 音质不好时优先查什么

优先级从高到低：

1. 训练数据是否干净、单说话人、少混响。
2. ContentVec HF 和 RMVPE 是否完整。
3. 是否加载了正确模型工作区的 `G_*.pth`。
4. 变调是否正确。
5. 特征检索比例是否过高。
6. 扩散打开后是否真的变好。

具体排查见 [Windows 常见问题排查](02_Windows常见问题排查.md)。
